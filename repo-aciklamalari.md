# GitHub repo açıklamaları

Her biri repo'nun kendi README'sine bakılarak yazıldı; uydurma yok.
`apply.sh` ile toplu uygulanabilir, ya da elle GitHub arayüzünden yapıştırılabilir.

| repo | açıklama |
|---|---|
| `dev-activity` | Measures real commit activity from local git history — private repositories included, aggregate numbers only |
| `LinguaSign` | Sign language translation and learning assistant — CNN+LSTM, MediaPipe and Transformer approaches compared |
| `LexoRead` | Reading assistant for dyslexia — summaries adapted to the reader's level, emotion-aware TTS (BART + T5) |
| `Audio-AI-Transformer-Comparison` | Benchmarks four speech transformers on the same task: HuBERT, wav2vec, WavLM and data2vec |
| `Emotion-Audio-Classifier` | Speech dataset builder for emotion analysis — downloads audio, trims silence, sorts into classes |
| `otonom-revenue-no-human-company` | Research and architecture for an autonomous multi-agent revenue pipeline for charities |
| `FilmWebApi` | Film browsing and watchlist API — ASP.NET Core, layered architecture, EF Core, SQL Server |
| `MarketAutomationWebApp` | Retail management system: customers, products, sales and stock. Java Spring + MySQL |
| `PomodoroApp` | Pomodoro timer for Android, written in Kotlin |
